# เครื่องมือครู — GitHub Pages / PWA

เว็บเครื่องมือครูสำหรับสร้างกระดาษคำตอบ ตรวจข้อสอบด้วยกล้อง และสรุปคะแนน

## ติดตั้งบน GitHub Pages

1. สร้าง repository แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจากชุดนี้ โดยคงโครงสร้างเดิม
2. ใน GitHub เปิด **Settings → Pages** แล้วตั้ง Source เป็น **GitHub Actions**
3. push ไป branch `main` หรือรัน workflow **Deploy GitHub Pages** ในแท็บ Actions
4. เปิด URL ที่ GitHub Pages แสดงให้
5. iPhone: เปิดใน Safari แล้วเลือก **แชร์ → เพิ่มไปยังหน้าจอโฮม**; Android: เลือก **ติดตั้งแอป** จากเมนูเบราว์เซอร์

Workflow จะ build และ deploy ให้อัตโนมัติเมื่อ push โค้ดไป `main`

## ข้อมูลและออฟไลน์

ข้อมูลห้องเรียน นักเรียน ชุดสอบ และคะแนนเก็บใน IndexedDB บนอุปกรณ์ที่ใช้อยู่ ไม่มีฐานข้อมูลหรือการซิงก์ข้ามอุปกรณ์ หลังเปิดเว็บขณะออนไลน์ครั้งแรก แอปจะเก็บไฟล์ที่จำเป็นเพื่อใช้งานออฟไลน์ได้ การล้างข้อมูลเว็บไซต์หรือถอนการติดตั้งอาจลบข้อมูล

ต้องใช้กล้องบน HTTPS ซึ่ง GitHub Pages รองรับ

## พัฒนาในเครื่อง

ต้องใช้ Node.js 22 ขึ้นไป และ pnpm 11.25.0

```sh
pnpm install
pnpm run dev
```

GitHub Pages แบบ project repository ใช้ base path ตามชื่อ repository อัตโนมัติ
