# เครื่องมือครู

เว็บแอปภาษาไทยสำหรับจัดการห้องเรียน สร้างกระดาษคำตอบ ตรวจข้อสอบจากกล้องมือถือ และสรุปคะแนน ส่งออกคะแนนเป็น Excel ได้

## ข้อมูลและการใช้งานออฟไลน์

- ข้อมูลห้องเรียน นักเรียน ชุดสอบ และคะแนนเก็บใน IndexedDB บนอุปกรณ์ที่กำลังใช้งาน ไม่ส่งไปฐานข้อมูลหรือเซิร์ฟเวอร์
- ติดตั้งเป็น PWA ได้ทั้ง iPhone และ Android; หลังเปิดเว็บขณะออนไลน์ครั้งแรก แอปและไฟล์ที่จำเป็นจะถูกเก็บไว้เพื่อเปิดและทำงานออฟไลน์
- ข้อมูลของ iPhone กับคอมพิวเตอร์แยกกัน ไม่มีการซิงก์อัตโนมัติ การล้างข้อมูลเว็บไซต์หรือถอนการติดตั้งอาจลบข้อมูลในอุปกรณ์
- การเปิดกล้องต้องอนุญาตสิทธิ์กล้อง และใช้ได้บน HTTPS เช่น GitHub Pages

## เริ่มพัฒนา

ต้องใช้ Node.js 22 ขึ้นไป และ pnpm 11.25.0

```sh
pnpm install
pnpm run dev
```

สร้างเว็บ static สำหรับ GitHub Pages:

```sh
pnpm run build:pages
```

ไฟล์พร้อมเผยแพร่จะอยู่ใน `dist-pages/` โดย workflow ใน `.github/workflows/pages.yml` จะ build และ deploy ให้อัตโนมัติเมื่อ push ไป branch `main` หรือสั่งรัน workflow เอง

สำหรับ Pages แบบ project repository ระบบตั้ง base path จากชื่อ repository ให้อัตโนมัติ ถ้าใช้ custom domain ที่ชี้มารากโดเมน ให้ตั้ง `PAGES_BASE_PATH=/` ในขั้น build

## วิธีเผยแพร่บน GitHub Pages

1. สร้าง GitHub repository แล้วอัปโหลดไฟล์โปรเจกต์นี้ โดยเก็บโครงสร้างโฟลเดอร์ไว้
2. ใน repository เปิด **Settings → Pages** แล้วตั้ง **Build and deployment → Source** เป็น **GitHub Actions**
3. push โค้ดไป branch `main` หรือเปิดแท็บ **Actions** แล้วรัน **Deploy GitHub Pages**
4. เมื่อ workflow สำเร็จ เปิด URL ที่แสดงใน **Settings → Pages**
5. บน iPhone เปิด URL ใน Safari แล้วเลือก **แชร์ → เพิ่มไปยังหน้าจอโฮม**; บน Android ใช้เมนูเบราว์เซอร์ **ติดตั้งแอป** หรือ **เพิ่มไปยังหน้าจอหลัก**

## สิ่งที่แอปรองรับ

เครื่องมือกระดาษคำตอบใช้งานตาม 4 ขั้นตอน: **เตรียมกระดาษ → เพิ่มนักเรียน → ตรวจคำตอบ → สรุปคะแนน** มีปุ่มไปต่อ/ย้อนกลับ และจำชุดสอบกับห้องที่เลือกระหว่างเปลี่ยนขั้น ดูรายละเอียดใน [ขั้นตอนกระดาษคำตอบ](docs/answer-workflow.md)

- ห้องเรียนและรายชื่อนักเรียน: เพิ่มทีละคน หรือนำเข้าจาก Excel/CSV
- ชุดสอบปรนัย ก ข ค ง ได้สูงสุด 60 ข้อ กำหนดคะแนนรายข้อและเฉลย
- บันทึกกระดาษคำตอบเป็น PDF โดยตรง ขนาด A4 หรือ A5 โดยไม่เปิดหน้าพิมพ์
- ลบชุดสอบพร้อมผลคะแนนของชุดนั้นได้ โดยมีหน้าต่างยืนยัน
- ตรวจคะแนนอย่างเดียวได้โดยไม่ต้องมีรายชื่อนักเรียน ถ่ายภาพแล้วจดคะแนนเองได้
- หากต้องการเก็บคะแนนในระบบ ให้ปิดโหมดตรวจคะแนนอย่างเดียว แล้วเลือกนักเรียน
- ดูสรุปและดาวน์โหลดผลคะแนนเป็น Excel
- รวมไฟล์ PDF และรูปภาพ: ลากหรือเลือกไฟล์ จัดลำดับ แล้วรวมและดาวน์โหลดเป็น PDF ไฟล์เดียว

## รวม PDF

เลือกเครื่องมือ **รวม PDF** จากหน้าแรก แล้วลากไฟล์ PDF หรือรูปภาพลงในพื้นที่เพิ่มไฟล์ หรือกด **เลือกไฟล์** เพื่อเพิ่มได้หลายรายการ รองรับ PDF, JPG, PNG และรูปแบบภาพที่เบราว์เซอร์เปิดได้ จากนั้นจัดลำดับด้วยการลากหรือปุ่มลูกศร แล้วกด **รวมและดาวน์โหลด PDF** เพื่อบันทึกไฟล์เดียวที่รวมแล้ว รูปภาพจะถูกจัดลงหน้า A4 ตามลำดับที่เลือก

ไฟล์ PDF จะถูกประมวลผลในเบราว์เซอร์บนอุปกรณ์นี้ และไม่ถูกส่งไปยังเซิร์ฟเวอร์

## สร้าง QR Code

เลือกเครื่องมือ **สร้าง QR Code** จากหน้าแรก กรอกข้อความหรือลิงก์แล้วกด **สร้าง QR Code** เพื่อดูตัวอย่าง จากนั้นกด **ดาวน์โหลด PNG** เพื่อบันทึกภาพลงอุปกรณ์


หมายเหตุ: GitHub Pages ให้บริการไฟล์เว็บแบบ static จึงไม่ต้องตั้งฐานข้อมูลหรือ secret สำหรับแอปนี้ ข้อมูลที่สร้างจะอยู่ในพื้นที่เก็บข้อมูลของเบราว์เซอร์บนแต่ละอุปกรณ์
