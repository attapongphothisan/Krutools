# ปรับเครื่องมือสำหรับใช้งานหน้างาน

- กระดาษคำตอบ: สร้าง PDF ในเบราว์เซอร์ด้วย pdf-lib โดยตรง ไม่มี window.print; กระดาษ A4 210×297 มม. และ A5 สองใบบน A4 รักษาตำแหน่ง QR และจุดอ้างอิงเดิม
- ลบชุดสอบ: ยืนยันก่อนลบชุดสอบ ผลตรวจ ลิงก์คะแนนปัจจุบัน และข้อมูลการส่งซ้ำของชุดนั้น รายชื่อและชุดสอบอื่นคงอยู่
- ตรวจคะแนนอย่างเดียว: เปิดเป็นค่าเริ่มต้น ไม่ต้องมีห้องหรือนักเรียน อ่านภาพแล้วดูคะแนน ตรวจใบถัดไปได้ ไม่สร้างผลคะแนนหรือเก็บคำตอบชั่วคราวเข้ารายชื่อ หากต้องการเก็บคะแนนให้ปิดโหมดนี้
- ลดจำนวนคลิก: ดาวน์โหลดกระดาษคำตอบ A4 ได้ตรงจากการ์ดชุดสอบ ส่วนสแกนข้อสอบเริ่มอ่านภาพทันทีหลังถ่าย/เลือกรูป และหน้าส่งออกเริ่มดาวน์โหลดทันทีเมื่อกดบันทึก โดยยังมีปุ่มดาวน์โหลดซ้ำให้
- กล้องเอกสาร: getUserMedia เปิดค้างและถ่ายต่อเนื่องในหน้าต่างเดียว ใช้แฟลชจังหวะถ่ายด้วย ImageCapture เมื่ออุปกรณ์รองรับ มิฉะนั้นเปิด torch เฉพาะช่วงสั้นขณะกดถ่าย กล้องที่เว็บสั่งแฟลชไม่ได้มีปุ่มไปเปิดกล้องระบบ
- หลังนำเข้าแต่ละภาพ ระบบค้นหากรอบกระดาษและแก้มุมแบบ perspective transform หากหาไม่ได้จะเก็บภาพครบและแจ้งให้ปรับเอง
- คลี่แนวข้อความโค้งอัตโนมัติโดยเทียบแนวหมึกระหว่างแถบภาพ ปฏิเสธบริเวณความมั่นใจต่ำ แยกแนวลาดตรงออกจากความโค้ง และซ่อนค่าปรับเองไว้ใต้ “ปรับเองเมื่อจำเป็น” วิธีนี้ไม่ใช่การสร้างรูปทรงสามมิติและไม่รับประกันกระดาษยับ/งอมากหรือข้อความที่ไม่เป็นแถว
- เพิ่มความคมอัตโนมัติโดยประเมินขอบภาพ ใช้ค่าปรับเองได้หากจำเป็น โหมดสีและโหมดขาวดำเดิมยังใช้ได้
- เลื่อนดูเอกสารด้วยการปัดซ้าย/ขวาบนภาพ แตะภาพย่อเพื่อข้ามหน้า และลากภาพย่อเพื่อจัดลำดับ
- ส่งออก PDF รวม/แยก หรือ JPG; JPG หน้าเดียวได้ไฟล์ภาพโดยตรง หลายหน้าได้ ZIP ตามลำดับ การหมุนและค่าปรับภาพติดไปกับไฟล์จริง

## ตรวจแล้ว

- ดาวน์โหลด A4/A5 จากหน้าเว็บจริง ตรวจขนาดหน้า A4 และเรนเดอร์ดูภาษาไทย/QR/ตำแหน่งกระดาษ
- นำ PNG ที่เรนเดอร์จาก PDF กลับเข้าเครื่องอ่านคำตอบ สำเร็จโดยไม่มีรายชื่อนักเรียน
- ตรวจคะแนนจากคำตอบที่กรอก แสดง 2/2 และเปิดตรวจใบถัดไปได้
- นำเข้าสองภาพ ค้นหาขอบของภาพกระดาษเอียงอัตโนมัติ และดาวน์โหลด ZIP ของ JPG เปิดไฟล์ทั้งสองได้
- ทดสอบการลบข้อมูลแบบ cascade การคลี่เส้นโค้งสังเคราะห์ การเพิ่มความคมชัด ชื่อไฟล์ และชุดทดสอบ PDF/มุม/สี/โดเมนเดิม

ยังต้องลองกล้องต่อเนื่องและไฟส่องบนโทรศัพท์จริง เพราะความสามารถของกล้องต่างกันตามระบบปฏิบัติการและเบราว์เซอร์
