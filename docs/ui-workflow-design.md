# หน้าตาเว็บเครื่องมือครู

แบบ Figma รุ่นก่อนหน้า: https://www.figma.com/design/86FDqesxAs1AsgRUg8ZWvG

## แนวทาง

- หน้ารวมเครื่องมือมีการ์ดเดียวสำหรับเครื่องมือกระดาษคำตอบ
- ภาพรวมกระดาษคำตอบใช้แถบเริ่มตรวจเป็นงานหลัก ตามด้วยรายการเตรียมกระดาษ/รายชื่อ พื้นที่สรุปคะแนน และชุดสอบที่เปิดทำงานต่อได้
- พื้นหลัง #F8FAFC แผงงานสีขาว จัดภาพรวมแบบ Bento Grid ใช้น้ำเงิน #3B82F6–indigo #6366F1 เป็นสีหลัก พร้อมเงานุ่มและขอบมน 12–14px
- ฟอนต์ Anuphan เก็บไว้กับเว็บ ใช้สถานะเขียว/เหลือง/แดงเฉพาะข้อมูลที่ต้องสื่อความหมาย
- ใช้แถบเมนูล่างบนมือถือและเมนูด้านข้างบนคอมพิวเตอร์
- หน้าตรวจจัดข้อมูลตามลำดับ เลือกชุดสอบและนักเรียน → ถ่ายภาพ → ยืนยันคะแนน
- แบบ Figma เป็นแนวทางรุ่นเดิมก่อนเปลี่ยนธีมและภาพรวมครั้งนี้ โค้ดเว็บไซต์เป็นหน้าตาปัจจุบัน
- แผน PDF และ PWA/offline อยู่ใน plan-document-scanner-to-pdf.md แยกจากงานปรับ UI นี้
