# ทดลองกระดาษพิมพ์จริงกับ iPhone

สถานะเริ่มต้น: ยังไม่ได้ทดสอบกับ iPhone และเครื่องพิมพ์จริงในสภาพแวดล้อมนี้

1. เปิดเว็บที่เผยแพร่ผ่าน HTTPS สร้างพื้นที่ทดสอบแยกจากข้อมูลจริง และบันทึกลิงก์
2. สร้างห้องทดสอบและนักเรียนสมมติ 2 คน สร้างชุดสอบ 60 ข้อ ตั้งเฉลยแบบ ก ข ค ง สลับวนไป และให้ทุกข้อ 1 คะแนน
3. พิมพ์ A4 เต็มแผ่นและ A5 สองใบต่อ A4 ที่ขนาดจริง 100% ปิดหัว/ท้ายของเบราว์เซอร์ ตัด A5 แยกเป็นคนละใบ
4. ใบแรกระบายคำตอบตรงเฉลยทั้ง 60 ข้อ ใบที่สองเว้น 1 ข้อและระบายสองคำตอบในอีก 1 ข้อ คะแนนที่คาดคือ 60 และ 58
5. เปิดพื้นที่เดียวกันด้วย Safari บน iPhone กดเปิดกล้องแล้วอนุญาตกล้อง ให้เห็น QR และมุมทั้งสี่ครบ ห้ามมีสองใบในเฟรม
6. ทดลองกระดาษบนพื้นเรียบในแสงธรรมชาติ แสงห้อง และเอียงกล้องเล็กน้อย เปรียบเทียบคำตอบที่อ่านกับกระดาษจริงก่อนยืนยันทุกครั้ง หากมีข้อไม่มั่นใจ ต้องมีจุดให้แก้ ไม่ควรยืนยันคะแนนโดยไม่ตรวจ
7. ตรวจว่าผลไม่ถูกบันทึกก่อนกดยืนยัน หลังยืนยันครั้งแรกเปลี่ยนไปนักเรียนคนที่สอง และเปิดคะแนนบนคอมพิวเตอร์ได้
8. ทดลองปิดกล้องและสลับแอป กล้องต้องหยุด; กลับมาให้เปิดกล้องใหม่ได้ ทดลองกรอกคำตอบเองได้หากยังไม่อนุญาตกล้อง
9. สแกนคนเดิมซ้ำ ทดสอบทั้งเขียนทับและเก็บครั้งใหม่ ตรวจประวัติและผลหลักให้ถูกคน
10. แก้เฉลยหนึ่งข้อ ดูว่าคะแนนผลหลัก ประวัติ และ Excel คำนวณตามเฉลยล่าสุด
11. ทดลองหลุดเน็ตขณะบันทึก เปิดเว็บใหม่แล้วกู้คำตอบที่ยังค้าง กดส่งใหม่ต้องไม่เกิดผลตรวจซ้ำ
12. บันทึกรุ่น iPhone/iOS เบราว์เซอร์ เครื่องพิมพ์ ดินสอหรือปากกาที่ใช้ พร้อมจำนวนแผ่น/ข้อที่อ่านคลาดเคลื่อน ปรับตัวอ่านแล้วทดสอบซ้ำก่อนนำไปตรวจข้อสอบจริง

ภาพจากกล้องไม่ควรถูกส่งใน request ไปยัง server หรือถูกเก็บในฐานข้อมูล/ไฟล์ การตรวจการส่งข้อมูลทำได้จาก Web Inspector หรือบันทึกเครือข่ายในอุปกรณ์ทดสอบ
