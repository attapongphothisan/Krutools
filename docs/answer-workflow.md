# ขั้นตอนเครื่องมือกระดาษคำตอบ

อัปเดต: 19 ตุลาคม 2569

## หน้าจอที่ปรับ

เปิดการ์ดกระดาษคำตอบแล้วเข้าสู่ขั้นเตรียมกระดาษทันที ใช้รูปแบบเดียวกับเครื่องมือสแกน PDF: หัวข้อกลางหน้า แถบลำดับขั้น เนื้อหาของขั้นปัจจุบัน และปุ่มย้อนกลับ/ไปต่อด้านล่าง

1. **เตรียมกระดาษ** — สร้างหรือเลือกชุดสอบ ตั้งเฉลย และเปิดกระดาษ A4/A5 เพื่อบันทึก PDF
2. **เพิ่มนักเรียน** — เลือกหรือเพิ่มห้อง เพิ่มรายชื่อทีละคนหรือนำเข้าจากไฟล์
3. **ตรวจคำตอบ** — ใช้ชุดสอบและห้องที่เลือก เลือกนักเรียน ถ่ายภาพหรือกรอกคำตอบ ตรวจทานแล้วกดยืนยันคะแนน
4. **สรุปคะแนน** — ใช้ชุดสอบและห้องเดียวกัน ดูผลและส่งออก Excel กลับไปตรวจต่อที่นักเรียนคนเดิมได้

ใช้แถบด้านบนเพื่อย้อนหรือข้ามไปขั้นที่ต้องการได้ หน้าที่ข้อมูลไม่พร้อมจะแสดงงานที่ต้องเตรียมและปุ่มไปทำงานนั้น ปุ่มถัดไปจากหน้ารายชื่อจะยังไม่เปิดเมื่อห้องที่เลือกไม่มีนักเรียน และชุดสอบที่ไม่มีเฉลยมีทางกลับไปตั้งเฉลยก่อนตรวจ

## การเชื่อมข้อมูลและป้องกันงานค้าง

- จำชุดสอบ ห้อง และนักเรียนระหว่างเปลี่ยนขั้นตอนหรือออกไปหน้าเลือกเครื่องมือในรอบที่เปิดแอปอยู่
- หลังสร้างชุดสอบหรือห้องใหม่ เลือกรายการนั้นให้ทันที
- หากยังตรวจไม่ครบทั้งห้อง แถบขั้นตรวจจะยังไม่แสดงเครื่องหมายเสร็จ
- ก่อนเปลี่ยนขั้นตอนขณะมีคำตอบที่ยังไม่ยืนยัน แสดงคำถามให้เลือกตรวจทานต่อหรือเปลี่ยนขั้นตอน
- ปิดปุ่มเปลี่ยนขั้นตอนระหว่างบันทึกคะแนน
- แก้ `workspaceRequest` ให้ส่งรหัสพื้นที่เก็บข้อมูลในเครื่องที่คงที่ตามฐานข้อมูล เพื่อให้ฉบับร่างบันทึกและกู้คืนได้ เดิม view ข้อมูลไม่มี `workspaceId` ทำให้บันทึกฉบับร่างด้วย key ที่ไม่ถูกต้อง
- การกู้คืนฉบับร่างทำเมื่อเปิดหน้าตรวจ ไม่ทำซ้ำทุกครั้งที่ข้อมูลคะแนนอัปเดต
- ขยับ cache ของ PWA เป็น v3 สำหรับไฟล์แอปรุ่นนี้

## การตรวจที่ทำแล้ว

- TypeScript และ build สำหรับ GitHub Pages ผ่าน ตรวจ lint ไฟล์ที่แก้ผ่าน
- ทดสอบ domain, การคำนวณคะแนน และการยืนยันผลเดิมรวม 12 กรณีผ่าน
- ใช้พื้นที่ทดสอบ `/answer-flow-review/` ซึ่งแยก IndexedDB จากข้อมูลของหน้าราก
- สร้างสองชุดสอบและสองห้อง เลือกชุดสอบ/ห้องที่ไม่ใช่รายการแรก แล้วเดินผ่านขั้นตอนจนถึงหน้าสรุปได้ตรงบริบท
- เพิ่มนักเรียนสองคน ทดสอบคำตอบที่ยังไม่ยืนยัน เปลี่ยนขั้นตอนแล้วกลับมากู้ฉบับร่างได้ครบ
- ยืนยันคะแนนแล้วเลือกนักเรียนคนถัดไป หน้าสรุปแสดงคะแนน 2/2 ของคนแรก และคนที่สองยังไม่ตรวจ
- ดาวน์โหลด Excel จริงและเปิดด้วย openpyxl ยืนยันชื่อชุดสอบ ห้อง รายชื่อ และคะแนนตรงกัน
- กลับจากสรุปแล้วคงนักเรียนคนถัดไปไว้ เปิดตัวอย่าง A4/A5 และเข้าออกเครื่องมือสแกน PDF ได้
- ตรวจทางแนะนำเมื่อเลือกชุดสอบที่ยังไม่มีเฉลย โดยไม่สลับไปชุดสอบอื่นเอง

ยังไม่ได้ทดสอบกล้องและการแตะบนโทรศัพท์จริงในรอบปรับหน้าจอนี้
